# 訪薬台（ほうやくだい）

在宅訪問のあとに、音声メモと要点から SOAP 形式の薬歴下書きを作り、院内の薬歴入力自動化（RPA）へ渡すまでの画面試作です。

掲載している患者・会話・数値はすべて架空です。この試作はブラウザの中だけで動き、入力内容を外部のサーバへ送りません。本番で想定している処理先は、院内に置く Mac mini 上のローカル音声認識とローカル LLM です。

## 見方

`index.html` を開くか、GitHub Pages の URL で同じ画面を開きます。

1. 起動画面のあと、「本日の訪問」から患者を選びます。
2. 用意してある音声メモを文字起こしするか、自分で要点を書きます。
3. 「下書きを作る」で S/O/A/P を編集します。
4. 「院内RPAへ渡す」で受け渡し待ちに入り、利用ログに残ります。
